# Won Ko — Autonomous Driving Control & Planning Portfolio

Standalone GitHub Pages project site focused on **Vehicle Control** (primary) and **Planning & Prediction** (secondary), with supporting work in state estimation, SLAM/localization, sensor calibration, and real-robot autonomy.

## Repository

Recommended repository name:

`autonomous-driving-control-portfolio`

After GitHub Pages is enabled from the `main` branch / repository root, the project site will be:

`https://won-ko.github.io/autonomous-driving-control-portfolio/`

## Publish

1. Create a public repository named `autonomous-driving-control-portfolio` under `Won-Ko`.
2. Upload the contents of this package directly to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.

## Structure

- `index.html` — standalone control/planning landing page
- `projects/index.html` — detailed projects and videos
- `cv/index.html` — embedded final CV
- `portfolio/index.html` — embedded final research portfolio
- `assets/` — style, profile, PDFs, videos, and posters

The site contains no navigation back to the general `won-ko.github.io` homepage and no visible GitHub profile link. All internal paths are relative so it functions independently as a GitHub Pages project site.
