Autonomously Driving Tricycle with Monocular Vision M.S. Project · UC Santa Cruz
Vision-based state estimation and stochastic optimal control for GPS-free autonomous navigation
Demo: stochastic Dynamic Programming / HJB policy execution in V-REP simulation
  • Stochastic optimal control: formulated a Dynamic Programming / HJB-style policy using robot-frame relative position, terminal heading, 11 turn-rate actions, diffusion noise, and a minimum-time / control-effort objective.
  • Validation: computed a 34,596-state policy and validated 23/23 terminal-success tests; matched simulations retained 100% terminal success and reduced mean arrival time by 2.2–4.9 s depending on the condition/baseline.
  • State estimation: developed EKF and second-order nonlinear state estimators for pose, velocity, and heading from noisy monocular-camera position measurements.
  • System identification: estimated propeller-actuated mechanism dynamics using batch least squares and recursive least squares in MATLAB/V-REP.
  • Camera calibration: implemented single- and two-pose monocular calibration using projective geometry and least-squares estimation.

Continental Intelligent Intersection - Real-World Vehicle Data Sep 2018 · Jun 2019
Continental-sponsored UC Santa Cruz project · radar/camera environment-model data from a real Walnut Creek intersection
  • Real-world sensor data: worked on a team project using Continental-provided temporal radar environment-model data and camera footage from a real intelligent-intersection test site.
  • Trajectory preprocessing: processed timestamped object trajectories using object ID, x/y position, velocity, heading, object type, and time-in-intersection features; built turn-direction labeling and cleaning around crosswalk line-segment intersections.
  • Sequence prediction: evaluated classical machine-learning and LSTM models for driver-intent / vehicle-trajectory prediction; team results reported 89.5% before-intersection and 98.6% after-intersection accuracy for the best LSTM configuration.
  • Safety reasoning: connected predicted vehicle intent and path geometry to critical scenarios including vehicle-path crossings, shared exit/lane conflicts, and vehicle-pedestrian crosswalk conflicts.

Robust Prior-Map Localization with Calibrated LiDAR Intensity Ongoing R&D
Global localization / relocalization for repetitive warehouse environments
Demo: LiDAR-intensity priormap localization and real-robot operation
  • Intensity calibration: built incident-angle/range-aware reflectivity calibration and keyframe-derived intensity priormaps that remain pose-consistent with the geometric map.
  • Global hypothesis ranking: implemented 20×60 Intensity Scan Context with bounded candidate/yaw prescoring before small-GICP geometric acceptance.
  • Validation: instrumented intensity MAE/RMSE and localization diagnostics; Recall@K, false-match, pose-error, and perturbation evaluation remains in progress.
Intensity Scan ContextPriormapsmall-GICPRelocalization
Localization stack reliability & optimization details
  • Improved a LIO-SAM / SC-LIO-SAM-derived ROS 2 stack with GTSAM/iSAM2, IMU-preintegration recovery, scan-to-map safeguards, abnormal-motion diagnostics, and map-integrity protection.
  • Added Hessian damping, Cholesky/SVD fallback, degeneracy projection, bounded optimization updates, and rollback for ill-conditioned scan-to-map cases.
  • Controlled single-factory-bag A/B testing reduced mean localization cycle time from 45.75 to 42.49 ms and P95 from 64.11 to 60.52 ms; repeat-bag validation remains pending.
